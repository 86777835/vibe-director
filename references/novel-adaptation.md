# 小说改编剧本指南

## 核心挑战

将小说/故事文本改编为短剧剧本，需要解决三个核心问题：
1. **篇幅压缩**：小说数千到数万字 → 每集 800+ 字（2-3分钟银幕时间）
2. **视觉化**：内心独白/旁白 → 外在动作/对话/视觉隐喻
3. **节奏适配**：小说的慢节奏铺陈 → 短剧的高密度冲突+反转

## 改编流程

### Step 1: 小说分析

从源文本中提取：
- **核心前提**：一句话故事线
- **主要冲突**：主角面对的核心困境
- **角色阵容**：所有重要角色 + 关系
- **关键场景**：最重要的 10-15 个场景/事件
- **Hook点**：适合作为每集开场或结尾的瞬间
- **世界观规则**：需要观众理解的设定

### Step 2: 结构映射

将小说叙事映射到短剧三幕结构：

| 短剧结构 | 集数占比 | 小说内容映射 |
|---------|---------|------------|
| 建置期 | 第1-12集 | 开篇设定、角色引入、核心冲突建立 |
| 对抗期 | 第13-50集 | 冲突升级、反转、角色成长、伏笔铺设 |
| 高潮期 | 第51-70集 | 终极对决、真相揭露、情感爆发 |

### Step 3: 角色处理

**角色简化原则**：
- 主角：保留，强化个性
- 对手：保留，可能合并相似对手角色
- 配角：合并功能相似的角色（如多个"情报提供者"合并为一个）
- 群演：删除或合并

**角色增强**：
- 给每个保留角色增加"爽点功能"（身份碾压、打脸、逆袭等）
- 强化角色的视觉辨识度（独特外貌、标志动作、口头禅）

### Step 4: 节奏压缩

**压缩策略**：

| 小说手法 | 短剧改编 |
|---------|---------|
| 长段心理描写 | 转为动作/表情/视觉隐喻 |
| 环境描写 | 转为开场镜头/空镜 |
| 闪回/回忆 | 转为画面切换/叠化/画外音 |
| 平行叙事 | 按时间线重排为线性叙事 |
| 慢节奏铺垫 | 删除，用对话快速交代 |
| 情感积累 | 用音乐+特写+慢镜头压缩 |

**每集结构**（参考 [rhythm-design.md](rhythm-design.md)）：
- 开场钩子（前5秒）：抓眼球
- 冲突升级（30秒-1.5分钟）：建立紧张感
- 高潮+悬念（30-45秒）：爽点释放 + 下集钩子

### Step 5: 对话改写

**小说对白 → 短剧台词**：
- 每行台词不超过30个字
- 删去所有"嗯""啊""那个"等语气词
- 每句话必须推动剧情或揭示性格
- 增加冲突性对话，减少信息性对话

**内心独白外化技巧**：

| 小说原文 | 短剧改编 |
|---------|---------|
| "她心想这个人不可信任" | 她的笔记本上这个名字被画了红圈 |
| "他感到一阵恐惧" | 手特写：微微颤抖，握紧拳头 |
| "这个决定会改变一切" | 她看向两扇门，深吸一口气，推开左边那扇 |
| "她想起小时候……" | 画面叠化到童年闪回，或老照片特写 |

### Step 6: 伏笔移植

将小说中的伏笔转化为短剧可执行的视觉元素：
- 小说中"隐约提到的" → 短剧中"一闪而过的镜头"
- 小说中"事后回忆的" → 短剧中"开场或过场的预览"
- 小说中"读者才知的" → 短剧中"观众视角特写"

## 改编规划模板

```markdown
# 改编方案

## 原作信息
- 原作名称：[名称]
- 原作长度：[字数]
- 核心类型：[题材]

## 改编决策
- 目标集数：[N]集
- 主角保留：[角色列表]
- 角色合并：[合并方案]
- 删除内容：[删除的场景/支线]

## 分集映射
| 集数 | 标题 | 对应原作章节/段落 | 核心冲突 |
|------|------|-----------------|---------|
| 01 | ... | 第X-Y章 | ... |

## 伏笔清单
| 伏笔 | 原作位置 | 短剧位置 | 视觉化方式 |
|------|---------|---------|-----------|
| ... | ... | ... | ... |
```

## 注意事项

- **尊重原作核心**：不改变原作的主题和情感内核
- **大胆删减**：短剧节奏优先，任何不推动剧情的内容都是负担
- **视觉化思维**：始终问"这段内容如何用画面表达？"
- **每集独立成章**：即使没看过前集，也应该能理解当前集的核心冲突
- **悬念驱动**：每集结尾必须有让观众想看下一集的理由
