# Obsidian Wiki 目录结构与规范

## 标准目录结构

```
项目名/                         ← Wiki Vault 根目录（用 Obsidian 打开此目录）
├── index.md                    ← 项目导航页
├── api-config.md               ← API 配置（首次设置）
├── 01_剧集/                    ← 剧集剧本
│   ├── 创作方案.md             ← 创作方案
│   ├── 分集目录.md             ← 分集目录
│   ├── 第1集_标题.md           ← 各集剧本
│   ├── 第2集_标题.md
│   └── ...
├── 02_角色/                    ← 角色档案
│   ├── images/                 ← 角色参考图（PNG/JPG）
│   │   ├── elara_vance_final.png
│   │   ├── marcus_blackwood.png
│   │   └── ...
│   ├── 艾拉拉·万斯.md         ← 各角色档案
│   ├── 马库斯·布莱克伍德.md
│   └── ...
├── 03_身份/                    ← 身份/角色类型（可选，适用于悬疑/狼人杀等）
│   ├── images/
│   ├── 狼人.md
│   └── ...
├── 04_机制/                    ← 规则与规范（可选）
│   ├── images/
│   ├── 故事板规范.md
│   └── ...
├── 05_时间线/                  ← 时间线（可选）
│   ├── images/
│   └── ...
├── 06_地点/                    ← 地点档案
│   ├── images/                 ← 地点参考图
│   ├── 白木教堂.md
│   └── ...
├── 07_传说/                    ← 背景传说（可选）
│   ├── images/
│   └── ...
└── 故事板/                     ← 故事板 + 视频输出
    ├── 第1集_标题/
    │   ├── scenes/             ← 故事板图片
    │   │   ├── S01E01_SB01_P01_航拍暴风雪.png
    │   │   └── ...
    │   ├── videos/             ← 生成的视频
    │   │   ├── S01E01_P01_航拍暴风雪.mp4
    │   │   └── ...
    │   ├── _archive/           ← 废弃素材归档
    │   └── seedance-prompts.md ← Seedance 提示词
    └── ...
```

## 必选 vs 可选目录

| 目录 | 状态 | 说明 |
|------|------|------|
| `01_剧集/` | **必选** | 剧本存放位置 |
| `02_角色/` | **必选** | 角色档案 + 参考图 |
| `06_地点/` | **必选** | 地点档案 + 参考图 |
| `故事板/` | **必选** | 故事板图片 + 视频 + 提示词 |
| `03_身份/` | 可选 | 适用于有身份隐藏机制的剧 |
| `04_机制/` | 可选 | 游戏规则/世界规则 |
| `05_时间线/` | 可选 | 时间线整理 |
| `07_传说/` | 可选 | 背景传说/世界观 |

## 文件命名规范

### 剧集文件
- 格式：`第N集_标题.md`
- 示例：`第1集_雪夜来客.md`、`第5集_处决.md`

### 角色文件
- 格式：`角色全名.md`（中文，含中间点）
- 示例：`艾拉拉·万斯.md`、`马库斯·布莱克伍德.md`
- 对应参考图：`images/{english_name}.png` 或 `images/{english_name}_final.png`

### 地点文件
- 格式：`地点名.md`
- 示例：`白木教堂.md`、`黑木瀑布镇.md`
- 对应参考图：`images/{english_name}.png` 或 `images/{english_name}.jpg`

### 故事板文件
- 格式：`S{季}E{集}_SB{编号}_P{beat编号}_{中文描述}.png`
- 示例：`S01E05_SB01_P01_不可置信.png`
- 季和集补零：S01（第一季）、E05（第五集）

### 视频文件
- 格式：`S{季}E{集}_P{beat编号}_{中文描述}.mp4`
- 示例：`S01E05_P01_不可置信.mp4`

## Obsidian 交叉引用语法

### 角色引用
```markdown
[[艾拉拉·万斯]]           ← 创建到角色档案的链接
[[艾拉拉·万斯|艾拉拉]]    ← 别名显示
```

### 地点引用
```markdown
[[白木教堂]]
[[黑木瀑布镇]]
```

### 图片嵌入
```markdown
![角色参考图](images/elara_vance_final.png)            ← 当前目录下的 images/
![故事板](../故事板/第1集_雪夜来客/scenes/S01E01_SB01_P01_xxx.png)  ← 跨目录引用
```

### 视频嵌入
```markdown
<video src="../故事板/第1集_雪夜来客/videos/S01E01_P01_xxx.mp4" controls width="100%"></video>
```

### 章节链接
```markdown
[[第5集_处决#P03：处决执行]]    ← 链接到文件的特定章节
```


## 参考图查找路径

故事板生成时，按以下路径查找参考图：

1. 角色图：`02_角色/images/*.png`、`02_角色/images/*.jpg`
2. 地点图：`06_地点/images/*.png`、`06_地点/images/*.jpg`
3. 身份图：`03_身份/images/*.png`（如存在）
4. 机制图：`04_机制/images/*.png`（如存在）
5. 传说图：`07_传说/images/*.png`（如存在）

匹配策略：用角色名/地点名的英文翻译在文件名中搜索（不区分大小写）。

## 归档规则

废弃的故事板和视频不删除，移入 `_archive/` 目录：

```
故事板/第N集_标题/
├── scenes/
├── videos/
├── _archive/                ← 废弃素材
│   ├── v1_SB01_P01_xxx.png
│   └── ...
└── seedance-prompts.md
```
